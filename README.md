# Wilson Mubbale Portfolio

A modern, responsive personal portfolio website built with:

- HTML
- CSS
- JavaScript
- GitHub Pages

## Before publishing

Replace these placeholders in `index.html`:

- `https://github.com/` with your actual GitHub profile/project links
- `https://www.linkedin.com/` with your actual LinkedIn profile
- `your-email@example.com` with your real email address

## Publish with GitHub Pages

1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.
8. Your site will be available at `https://yourusername.github.io/`.

If your GitHub username is `wilsonmubbale`, the address would be:
`https://wilsonmubbale.github.io/`
